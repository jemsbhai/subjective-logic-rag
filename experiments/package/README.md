# SL-RAG A100 Experiment Package

## Overview

This package runs the large-model experiments for the SL-RAG paper on A100 GPUs.
It evaluates Llama 3.1 70B and Qwen 2.5 72B on HotpotQA and MuSiQue benchmarks
with the SL-RAG pipeline and all UQ baselines.

## Requirements

- 2× NVIDIA A100 80GB GPUs
- ~400GB disk space (models + datasets + results)
- Python 3.10+
- HuggingFace account with Llama access (accepted Meta license)
- `HF_TOKEN` environment variable set

## Quick Start

```bash
# 1. Clone the repo
git clone <repo_url> xrag
cd xrag/phase1

# 2. Set HuggingFace token
export HF_TOKEN=hf_your_token_here

# 3. Run setup (installs deps, downloads models)
bash experiments/package/setup.sh

# 4. Run experiments (prioritized — stop anytime)
bash experiments/package/run_a100.sh
```

## What Gets Run (in priority order)

### Priority 1: Main experiments (~4-6 hours)
- HotpotQA + MuSiQue with Llama 3.1 70B (FP16, no quantization)
- Full SL-RAG pipeline + all 6 baselines including semantic entropy
- 500 examples per benchmark

### Priority 2: Corruption sweep (~8-12 hours)
- 4 corruption types (distractor, contradiction, missing, adversarial)
- 3 levels each (25%, 50%, 75%)
- Both benchmarks × Llama 70B
- 24 experiment runs total

### Priority 3: Qwen 72B (~4-6 hours, if time permits)
- Same as Priority 1 but with Qwen 2.5 72B
- Cross-architecture generalization evidence

## Sending Results Back

After experiments complete:

```bash
tar czf results_a100.tar.gz experiments/results/
```

Send `results_a100.tar.gz` back. Each result is a self-contained JSON
with the full config embedded, so results are fully reproducible.

## Troubleshooting

**Out of memory**: If 70B FP16 doesn't fit on 2× A100, edit the config
to set `load_in_4bit: true`. This reduces VRAM to ~35GB per GPU.

**Model download fails**: Ensure `HF_TOKEN` is set and you've accepted
the Llama license at https://huggingface.co/meta-llama/Llama-3.1-70B-Instruct

**Dataset download fails**: Datasets are downloaded from HuggingFace on
first use. Ensure internet access is available.

```
    ├── setup.sh                 # One-time setup
    └── run_a100.sh              # Run all experiments
```
